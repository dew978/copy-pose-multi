# Copy Pose (Multi)

호스트 1명과 **참가자 1~8명**이 각자의 카메라로 즐기는 온라인 포즈 게임입니다. 기존 `dew978/copy-pose`와 별도로 배포하는 프로젝트입니다.

## 플레이

1. 호스트가 PC에서 방을 만들고 라운드(1/3/5), 난이도(전체/하/중/상/최상 랜덤)를 선택합니다.
2. 초대 링크 또는 8자리 방 코드를 참가자에게 전달합니다. 호스트는 참가 인원에 포함되지 않으며 카메라가 필요하지 않습니다.
3. 참가자는 각자 기기에서 입장하고 **카메라 켜고 참여**를 누릅니다. 전신이 보이도록 공간을 확보합니다.
4. 호스트가 **참가자 확정 · 자동 시작**을 누릅니다. 전원 전신 인식이 3초 동안 유지되면 시작합니다.
5. 각 포즈를 5초 동안 따라 합니다. 같은 기준으로 계산한 유사도의 라운드 평균이 가장 높은 참가자가 우승합니다. 공동 1위는 해당 참가자끼리 추가 라운드를 진행합니다.
6. 승자의 화면에는 몸을 둘러싼 빛, VICTORY, 폭죽이 나타납니다. 1명으로도 연습할 수 있습니다.

40개 포즈(난이도별 10개)가 준비되어 있습니다. 제한된 라운드 안에서는 중복 없이 랜덤으로 출제합니다. 준비가 풀리면 3초부터 다시 시작하고, 한 명이라도 채점 자료가 부족하면 같은 포즈로 재도전합니다. 호스트는 모집 화면으로 돌아가 참가자를 내보내거나 경기를 다시 시작할 수 있습니다.

## 구조와 데이터

- 정적 ES 모듈 앱. GitHub Pages의 HTTPS에서 실행합니다. 파일 다운로드 후 `content://`로 여는 방식은 지원하지 않습니다.
- MediaPipe Tasks Vision **0.10.21**, Pose Landmarker Full **float16/1**이 참가자 기기에서 관절을 추정합니다. 호스트가 관절 좌표로 같은 유사도 공식을 적용합니다.
- 점수는 신체 크기/화면 위치에 영향을 덜 받도록 관절 사이 방향과 팔꿈치/무릎 각도를 비교한 **게임용 유사도**입니다. 생체역학적 정확도나 동작의 안전성을 측정한 수치는 아닙니다.
- 단일 프레임 최고점 대신 350~650ms, 최소 3회 관찰의 평균 최고값을 사용합니다. 인식되지 않은 관절로 임의 점수를 만들지 않습니다.
- PeerJS **1.5.5**의 공용 PeerServer가 연결 신호를 중개합니다. 영상과 자세 좌표는 WebRTC로 호스트와 참가자 사이에 전달합니다. 직접 연결이 어려우면 PeerJS 공용 TURN을 통해 암호화된 패킷을 중계할 수 있습니다.
- 참가자는 최대 너비 480px/12fps의 카메라 영상을 호스트에게 전송합니다. 호스트는 1280×720/12fps 격자 영상을 만들어 각 참가자에게 하나의 스트림으로 돌려줍니다. 8명일 때는 8명+제시 포즈의 3×3 격자입니다. 전신 영상은 자르지 않고 비율을 유지합니다.
- 영상과 좌표는 같은 방 안에 공유됩니다. 마이크는 요청하지 않으며 녹화, 영상 업로드 API, 데이터베이스는 없습니다. 이름·재접속 토큰은 참가자 탭의 sessionStorage에만 저장합니다.
- 재접속 토큰은 공유 상태에 포함하지 않습니다. 호스트는 입장이 승인된 참가자의 영상 호출만 수락하며, 최대 8명 및 경기 중 새 참가자 차단을 적용합니다.
- 호스트 탭을 닫으면 방이 끝납니다. 새로고침 후 복구되는 영구 방은 아닙니다. 참가자는 같은 탭에서 같은 방으로 다시 입장할 때 진행 중인 자리로 복귀할 수 있습니다.

## 운영 범위

호스트는 PC와 안정적인 인터넷 연결을 사용하고 탭을 화면에 열어 두세요. 호스트의 업로드 대역폭은 참가 인원에 따라 늘어납니다. 참가자 화면에서 영상과 자세 정보를 공유한다는 안내 후 직접 카메라를 켭니다.

이 버전은 **PeerJS 기본 STUN 및 공용 TURN**으로 직접 연결을 우선하며, 가능한 경우 중계를 사용합니다. 공용 중계의 용량과 가용성은 보장되지 않습니다. 일부 학교/기업망, 대칭 NAT, 엄격한 방화벽에서는 연결되지 않을 수 있습니다. 외부망에서 안정적으로 운영하려면 인증된 TURN 중계 또는 SFU/신호 서버를 추가해야 합니다. 공용 신호 서버의 가용성도 영향을 줍니다. 이는 8명이 실제 서로 다른 네트워크에서 동시 접속해 검증된 서비스 수준 보장을 뜻하지 않습니다.

점수 계산은 호스트가 수행하지만 참가자의 관절 데이터 자체를 위조하는 행위까지 방지하는 경쟁 대회용 안티치트는 아닙니다.

## 개발과 검증

Node 22 이상에서 외부 npm 의존성 없이 게임·방 로직 테스트를 실행합니다.

```sh
npm test
bash scripts/download-assets.sh
python3 -m http.server 8080 --directory dist
```

개발 PC에서 `http://localhost:8080`으로 열 수 있습니다. 다른 기기에서 LAN HTTP 주소를 여는 경우에는 카메라가 차단되므로 HTTPS 배포 주소를 사용하세요.

자동 검증은 1~8명/9명 제한, 8명 5라운드, 단독 연습, 전원 준비, 인식 실패 재시도, 동점 결승, 재접속, 지연/중복/잘못된 데이터, 카메라 제약 조건과 점수 계산을 포함합니다. 합성 관절 및 가상 데이터 채널 테스트이며 실제 카메라/외부망 WebRTC 부하 테스트와는 별개입니다.

## GitHub Pages 배포

1. `copy-pose-multi` 공개 저장소를 만들고 `main`에 이 프로젝트를 올립니다.
2. 저장소 **Settings → Pages → Source → GitHub Actions**를 선택합니다.
3. **Actions → Deploy Copy Pose Multi** 워크플로를 실행합니다.
4. 테스트 후 AI 자산을 내려받아 `dist`를 배포합니다. 예상 주소는 `https://dew978.github.io/copy-pose-multi/`입니다.

루트의 `index.html`도 게임을 가리켜 README만 첫 화면으로 표시되지 않도록 합니다. AI 자산은 배포 시 포함되며, 로컬 개발 시 없으면 지정된 CDN에서 가져옵니다.
